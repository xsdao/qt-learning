五、工程结构与构建特点

每个示例的典型结构

sampX_Y/
├── CMakeLists.txt      # 构建配置（AUTOUIC/AUTOMOC/AUTORCC）
├── main.cpp            # 入口（QApplication + 窗口 + exec）
├── mainwindow.h/.cpp   # 或 widget/dialog 类
├── mainwindow.ui       # 界面（Designer XML）
└── res.qrc             # 资源（可选）

CMake 要点（全书统一）

set(CMAKE_AUTOUIC ON)   # .ui → ui_xxx.h
set(CMAKE_AUTOMOC ON)   # Q_OBJECT → moc
set(CMAKE_AUTORCC ON)   # .qrc → qrc_xxx.cpp
find_package(Qt6 REQUIRED COMPONENTS Widgets)
qt_add_executable(app ...)
target_link_libraries(app PRIVATE Qt6::Widgets)

⚠️ 与 qmake 的差异（你已踩过）

  • qmake 工程有 .pro；CMake 工程只有 CMakeLists.txt
  • CMake 不会自动扫描目录：新增 .cpp/.h/.ui 必须手动写进 qt_add_executable（这是从 qmake/Qt Creator 转过来最容易踩的坑）
  • 本书 81 个工程中 79 个用 CMake，仅 Chap11 插件、Chap18 工具保留 .pro

七、常见坑与注意事项（基于源码检查）

  1. 仅 3 个工程无 .ui：samp2_3CodeUI（纯代码）、samp18_3Deploy/samp18_4Installer（非界面）。别把后两者当“纯代码 UI”学。
  2. samp2_4CMakeGUI、samp11_3/4、samp15_2 等无 main.cpp：是库/构建/服务端样例，不能单独运行。
  3. Chap11 的 samp11_3StaticLib / samp11_4SharedLib 目录里混入了构建产物（.lib/.dll/.ninja_*），说明是别人编译后的残留，学习时忽略这些二进制。
  4. Chap17 需要 SerialPort 模块；Chap12 需要 Charts；Chap13 需要 DataVisualization；Chap16 需要 Multimedia——Qt 安装时要勾选对应模块。
  5. 中文注释存在编码问题：部分文件注释显示为乱码（源文件可能是 GBK 保存），用 VS Code 打开可切编码查看。
  6. 本书基于 Qt 6.2/6.4 编写，你用的是 6.8.3，个别 API/CMake 写法可能有小差异（一般 CMake 通用）。
